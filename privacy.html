StreamSync 개인정보처리방침

시행일: 2026년 11월 7일

StreamSync(이하 "이 도구")는 사용자가 자기 PC에서 직접 실행하는 로컬 프로그램입니다. 이 도구의 제작자는 사용자의 데이터를 수집하거나 보관하지 않습니다.

1. 접근하는 정보

사용자가 Google(YouTube) 및 네이버(치지직) 로그인 화면에서 직접 허용한 경우에만, 사용자 본인 계정의 다음 정보에 접근합니다.

  • YouTube: 본인 채널의 라이브 방송과 동영상 정보(제목, 설명, 태그, 카테고리, 녹화 날짜, DVR 설정), 썸네일, 재생목록
  • 치지직: 본인 채널 정보와 방송 설정(제목, 카테고리, 태그)

2. 이용 목적

사용자가 요청한 방송 정보(제목, 설명, 카테고리, 태그, 썸네일, 재생목록)를 사용자 본인의 채널에 입력하는 데에만 사용합니다. 광고, 분석, 프로필 작성 등 다른 목적으로는 사용하지 않습니다.

3. 저장 위치

로그인 토큰, 설정, 방송 기록, 썸네일 이미지는 모두 사용자 PC의 이 도구 폴더 안에만 저장됩니다. 제작자나 다른 서버로 전송되지 않습니다.

4. 제3자 제공

이 도구는 사용자의 정보를 제3자에게 제공하거나 판매하지 않습니다. 방송 정보를 입력하기 위해 Google(YouTube Data API)과 네이버(치지직 API)에 요청을 보내는 것 외에는 외부로 데이터를 보내지 않습니다.

5. Google 사용자 데이터

이 도구가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

6. 접근 권한 해제와 삭제

  • Google: Google 계정 → 타사 앱 및 서비스에서 언제든 접근 권한을 해제할 수 있습니다.
  • 치지직: 네이버 계정의 연결된 서비스 관리에서 해제할 수 있습니다.
  • 이 도구 폴더의 data 폴더를 지우면 PC에 저장된 모든 정보가 삭제됩니다.
