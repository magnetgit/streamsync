StreamSync

치지직 · 유튜브 동시송출 방송 정보 자동 입력 도구

StreamSync는 개인 방송인이 자기 PC에서 실행하는 로컬 도구입니다. OBS 독에 띄워 두고 게임 이름을 입력하면, 본인의 치지직 방송 설정과 유튜브 라이브 방송에 아래 정보를 한 번에 입력합니다.

  • 방송 제목과 방송 내용(설명)
  • 카테고리(게임)와 태그
  • 썸네일(OBS 화면 캡처에 날짜와 게임 이름을 넣은 이미지)
  • 유튜브 녹화 날짜, DVR 설정, 재생목록 추가

이 도구는 서버를 따로 두지 않습니다. 모든 작업은 사용자 PC에서 이루어지며, 사용자가 직접 로그인해 허용한 본인 계정에만 접근합니다.
